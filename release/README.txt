VVVVVV - Xbox 360 (libXenon) - installation

WHAT IS IN THIS ZIP
-------------------
  vvvvvv.elf32              The game executable (bare-metal PowerPC ELF32).
  README.txt                This file.
  NOTICE.txt                Licence and attribution notices.
  SHA256SUMS.txt            Checksums of the files in this ZIP.
  data/README.txt           Where the game data must go.
  data/MANIFEST-required.txt  Every data file the game needs, with paths.

The public ZIP does NOT contain VVVVVV's graphics, sounds or music. Those are
proprietary and may not be redistributed. You must supply them yourself, for
personal use, from the official free Make and Play Edition:

  https://thelettervsixtim.es/makeandplay/

(Download "data.zip" from that page.)

HOW TO INSTALL
--------------
The game reads its assets from the ROOT of the FAT32 volume it mounts (the USB
stick). It does NOT look next to the .elf32 file and it does NOT use a "current
directory" - libXenon has none. The location of vvvvvv.elf32 is irrelevant;
what matters is that the USB stick root contains a "data" folder.

1. Use a FAT32-formatted USB stick.
2. At the ROOT of the stick create a folder named:  data
3. Extract the official data.zip INTO that folder, so the stick ends up like:

     <USB ROOT>/
       data/
         graphics/            (21 .png files)
         sounds/              (28 .wav files used by this port)
         vvvvvvmusic.vvv
       vvvvvv.elf32           (may be here or in any other folder)

   Example final paths the game opens:
     /data/graphics/tiles.png
     /data/graphics/font.png
     /data/sounds/jump.wav
     /data/vvvvvvmusic.vvv

   Do NOT put "graphics/" directly at the stick root; it must be inside data/.

4. Run vvvvvv.elf32 with Aurora's File Manager or XeLL.

On first boot the game creates /user/saves, /user/levels and /user/logs on the
same volume.

If the loading screen stops with "Missing game data", the paths above are not
correct. It prints the missing file names. Check capitalisation and that the
data folder is at the stick root (not inside the folder with the ELF).

REQUIRED FILES
--------------
See data/MANIFEST-required.txt for the exact list (50 files):
  - 21 PNG files under data/graphics/
  - 28 WAV files under data/sounds/
  - 1 music pack: data/vvvvvvmusic.vvv

Optional (not required by this port):
  - data/mmmmmm.vvv              alternate MMMMMM soundtrack
  - data/music/*.ogg             only used when rebuilding with VVV_COMPILEMUSIC
  - data/BinaryMusic.vvv         generated by that build mode
  - data/levels/*.vvvvv          extra Make and Play levels (not used by the
                                 built-in main game; custom levels belong in
                                 data/../user/levels/)

BUILDING YOUR OWN COMPLETE ZIP
------------------------------
If you own the data, you can have the packaging tool check and bundle it:

  python3 tools/package_release.py --elf xenon/vvvvvv.elf32 \
      --data /path/to/data --out dist/vvvvvv-elf32-with-data.zip

It lists every required asset, fails if any is missing, and warns that the
result contains proprietary assets and must not be redistributed.
